# Run & Add

Onboarding guide for running recorded flows and adding them into the framework.

> **Onboarding step 2 of 4** | Previous: [Setup & Environment](../01-getting-started/README.md) | Next: [Reference & Architecture](../03-reference/README.md)

## Journey

| Step   | File                                            | What you do                                                          |
| ------ | ----------------------------------------------- | -------------------------------------------------------------------- |
| 2 of 4 | [Recording Tests](./recording-tests.md)         | Run codegen, capture selectors, and turn actions into framework code |
| 2 of 4 | [Selector Strategies](./selector-strategies.md) | Choose stable locators before adding selectors to config             |
| 3 of 4 | [Writing Tests](./writing-tests.md)             | Move captured behavior into helpers, fixtures, and thin specs        |
| 3 of 4 | [Data-Driven Testing](./data-driven-testing.md) | Decide whether a flow becomes DDT and scaffold the data loop         |

## Recommended Path

1. Capture the flow in [Recording Tests](./recording-tests.md).
2. Convert the capture into helpers in [Writing Tests](./writing-tests.md).
3. Use [Selector Strategies](./selector-strategies.md) when adding locators.
4. Use [Data-Driven Testing](./data-driven-testing.md) when the flow repeats with different data.
