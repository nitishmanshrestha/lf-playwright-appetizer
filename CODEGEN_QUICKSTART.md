# Codegen Quick Start

Codegen is a discovery aid after project intake:

```bash
npx playwright codegen "$BASE_URL"
```

Use it to verify locators and interactions, then move selectors into config and behavior into
helpers. Do not let generated code define business expectations or bypass the requirement
registry.

See [`DISCOVERY.md`](DISCOVERY.md) and [`docs/START-HERE.md`](docs/START-HERE.md).
